# AI Meeting Intelligence System

AI-powered platform for audio/video meeting transcription and analysis using FastAPI, Next.js, Faster-Whisper, PostgreSQL, and Groq API.

## Features
- Audio/video upload
- Timestamp transcription
- AI summaries
- Action items
- Meeting insights

## Tech Stack
- FastAPI
- Next.js
- PostgreSQL
- Faster-Whisper
- Groq API
